# Sno Queens website

The website for Sno Queens, a 100% Black female-owned independent power producer based in Durban, South Africa.

It is a static one-page site with no build step. To publish it, upload the contents of this repository to the web host's public folder, such as `public_html` in cPanel.

Photo and font licences are listed in [CREDITS.md](CREDITS.md).
